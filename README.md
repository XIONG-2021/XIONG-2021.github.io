# Jingfeng Xiong — GitHub Pages

静态个人主页，内容基于公开的 [Google Scholar](https://scholar.google.com/citations?hl=zh-CN&user=JnBEkR8AAAAJ) 与 [N-HE1 STM32 Gitee 仓库](https://gitee.com/xndwzjj/n-he1-stm32)。

## 部署

1. 新建 GitHub 仓库；若要作为个人主页，仓库名应为 `<你的 GitHub 用户名>.github.io`。
2. 上传本目录所有文件。
3. 在仓库 **Settings → Pages** 中选择从 `main` 分支的根目录部署。

网站无需构建步骤，访问 `index.html` 即可预览。
